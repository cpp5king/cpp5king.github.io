# 第9條2.9背景流程

由2.8完整複製。超標項目直接顯示背景數值；「無法取得背景音量」是非必答的主動勾選例外。勾選時清除現場背景數值並要求原因，取消時清除原因及特殊背景資料後恢復輸入。上游事實、區域、時間或风速變更亦清除背景／例外資料。

工廠核備背景保留既有適用條件；例外啟用後仍可依既有全年運轉及核備有效性流程處理全頻，未自行新增規則。

兩種無效量測的結束公文改為本次核定之「該噪音值無法作為執法依據」文字，出口、重測、D<3停止、D=3修正及其他公式／判斷均不變。
