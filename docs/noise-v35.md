# 3.5 UI與量測流程修正

由 `C:\稽查助手\稽查助手3.3` 完整複製，僅修改本版本。雙擊本版本 `start.cmd` 即可完全離線啟動。沒有新增網路、套件或服務依賴。

## 操作改動

1. `a9Exit` 在主流程改為內部computed狀態，沒有輸入DOM。`persistedKeys` 只讓表單在事件間攜帶內部狀態，不讓使用者編輯。原來的顯示問題來自後段showWhen轉displayWhen覆蓋了隱藏條件。
2. 噪音單選卡只渲染真實答案，不再建立空字串的「請選擇／尚待確認」卡片。初始全部未選。方向鍵與單選語意保留；複選仍為checkbox。
3. 噪音主流程與近鄰入口可按「填入兩份草稿」檢查必要資料；未完成時只顯示具體錯誤，不會產生placeholder公文。流程導引仍照常顯示。
4. 未量測＋設備未啟動：擴音設施直接引用既有type label；其他公告設施引用已選facility label。手填音源欄隱藏，舊手填值不會覆蓋該名稱。工廠、娛樂及營業場所仍要求手填音源。量測分支不受此自動帶入影響。
5. 場所欄及驗證使用「稽查場所／被陳情對象」與「請填寫稽查場所／被陳情對象」，資料key與公文句型不變。
6. 第8條以已選行為的label產生標準事實，營建與室外擴音採使用者提供的完整動作句。自由描述以「補充現場事實：」附加，不取代標準事實。機具與作業內容若都有填，使用既有「使用…進行…」句型；只填一項則以該項名稱附加。第8條成立條件不變。
7. 以下標為選填：第8條使用機具、作業內容、現場事實描述；原本不阻擋流程的營建核准附加查核三題；Leq、Lmax、低頻各項；背景量測例外。各實測數值可個別留空，但量測分支仍至少需要一項有效實測值。條件成立後的背景值或無法取得原因仍必要，未標選填。
8. 噪音數值控制項使用text＋decimal inputMode，保留原始字串（包括輸入中的`1.`）。原有input事件仍重算提示，但相同值不回寫控制項，不重建DOM或移動游標。數值有效性仍由既有量測器檢查，風速5 m/s邊界不變。

## 歷次量測

`src/noise-attempts.js` 提供記憶體量測歷史。按重測時先快照本次無效量測，再呼叫既有restart清除本次數值，進入下一次量測。風速超限與D小於3才顯示各自重測／結束操作。

歷史存在內部 `measurementAttempts`，為JSON序列化陣列，以相容現有字串表單狀態；`NoiseAttempts.list()`取得物件陣列。每筆含：

```text
number                 第幾次
context                 當時日期、HH:mm、管制區、type、facility
point / wind            當時測點與原始風速字串
items[]                 該次實際輸入項目
  id / label / raw      項目與原始值
  standard              當時適用標準
  background            原背景值
  annualBackground      核備背景值（若有）
  difference            引擎已算出的D（若有，完整精度）
  corrected             修正後數值（若有，完整精度）
status / reason         原狀態碼與無效原因
unavailableReason       無法取得背景原因（若有）
```

第1次重測後成為歷史快照；第2次為目前表單的獨立數值。再次重測時才把第2次加入歷史。歷史顯示於「歷次量測紀錄」，保留原管制區／標準，不因上游修改而改寫。

最終引擎只接收目前這次輸入，**不將歷史陣列傳入assess**。第二次有效則以第二次判定；目前仍無效而選結束則沿用原風速／D小於3模板。歷史僅供查看，沒有擅自將過往無效數據混入最終公文。重新開始案件清空所有輸入及歷史；關閉或重新載入頁面也會清空，沒有寫入磁碟、資料庫或雲端。

## 顯示精度與時間

`src/noise-format.js`：

- `correctedVolume(number)`：只供修正後音量顯示使用，`toFixed(1)`。第9條公文、修正明細、歷史修正值共用。內部公式及比較仍是完整精度，例如顯示65.0但實際65.01大於標準65時仍超標。
- 歷史D不套用音量的一位小數規則，避免2.99被顯示成3.0而誤解停止條件。
- `validTime()`：僅接受00:00～23:59的HH:mm。
- `inspectionHour()`：23:30→23時許、00:40→0時許、08:05→8時許。第8條、第9條量測及未量測文件共用。

主流程時間控制項明確為text，帶HH:mm pattern及提示，故不依賴瀏覽器locale，不出現AM/PM。畫面摘要與歷史保留HH:mm；法規引擎也繼續使用完整分鐘。只有公文格式省略分鐘。
