# 水污染 4.2.1 更新說明

## 現場稽查 → 案件研判

4.2.1 新增「繼續案件研判」交接。只有現場查察完成並顯示初步研判後才出現交接按鈕；按下後把現場已填的共同案件事實帶入「案件研判（完整母法）」。

交接資料包含可共用的管制主體、廢（污）水／污染物、水源、去向、實際排放、地面水體、事故、採樣與證據等欄位。目標模板的顯示條件、computed flags 與法律研判均由 water-main workflow 重新計算。

## 案件文字

水污介面將共用草稿動作名稱預留為「產生案件文字」。目前尚未核定水污稽查紀錄與民眾回覆正式模板，因此仍為 preview-only，不生成看似正式但未核定的假草稿。
