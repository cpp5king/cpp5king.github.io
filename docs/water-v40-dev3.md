# 水污染模組 4.0-dev3

## 本版目的

延續 dev2 的統一事實層、多條文規則引擎與決策流程，新增三組母法支線：

- 水污染防治法第28條：輸送／貯存設備疏漏。
- 水污染防治法第30條第1項第2款：污染物棄置。
- 水污染防治法第32條第1項：排放於土壤／注入地下水體。

本版仍不納入《水污染防治措施及檢測申報管理辦法》細部義務，也不產生水污公文草稿。

## Node 002 改造

Node 002 先確認案件主要物質／污染態樣：廢（污）水、污泥、水肥、酸鹼廢液、垃圾、建築廢料、其他污染物或未知。

- 廢（污）水：沿用認水、實際排放、追水、許可、水質與異常水路流程。
- 其他污染物：可進入第30條棄置支線。
- 事業或污水下水道系統如涉及污染物或廢（污）水的輸送／貯存設備疏漏，可另進第28條。

## 第28條

分開處理：

1. 有疏漏至水體之虞且未採必要維護、防範措施。
2. 已疏漏致污染水體但未立即採緊急應變措施。
3. 已疏漏致污染水體但未於事故發生後3小時內通知當地主管機關。

人為開閥、私管或主動抽排不直接認定為設備疏漏，介面會提示優先回查第14條與第18條之1。

## 第30條

第1項第2款規則必須同時確認：

- 行為地點位於水污染管制區。
- 物質屬垃圾、水肥、污泥、酸鹼廢液、建築廢料或其他污染物。
- 存在棄置行為。
- 行為位於公告指定水體或其沿岸規定距離內。

一般管線排放廢（污）水不因水質髒或屬污染物就自動套用第30條棄置支線。

## 第32條

### 排放於土壤

確認廢（污）水、實際排放、實際進入土壤及土壤處理許可。若有有效許可，本版僅判定「無合法土壤處理資格」方向不成立；是否依許可、水質與水措細部運作仍留待後續模組。

### 注入地下水體

必須另確認廢（污）水實際進入地下水體／地下含水層。僅有「管線往地下」或排放口位於地面以下，不足以自動認定注入地下水體。
