# 水污染模組 4.0-rc1

## 定位

4.0-rc1 是水污染 V1「母法主體完成候選版」。正式程式完全離線、規則式、確定性運作，不使用 AI 或網路查法。既有空污與噪音功能保留。

## 主流程

認人 → 認水／污染物 → 追查最終去向 → 查資格 → 對許可／核准 → 查水質 → 查異常 → 補證據 → 全案研判。

「沒有向外排放」不再中止追水，仍可繼續判斷貯留、回收、委外等去向。

## 判斷原則

每個規則的必要要件均以 `yes / no / unknown` 建模。規則結果只有：

- `established`：構成要件完整方向
- `notEstablished`：至少一必要要件明確不成立
- `insufficient`：必要要件仍未知／證據不足
- `notApplicable`：主體或情境不適用

道路側溝不因名稱自動認定為地面水體；地下管線不等於注入地下水體；不明管線不等於繞流；資料不一致不等於 §35 明知不實。

## 全案輸出

- A｜本次查無違規事證
- B｜構成要件完整
- C｜事證不足
- D｜重大／緊急污染

D 優先於告發研判。B 只代表至少一個法律問題的構成方向完整，仍可同時存在其他待查支線。A 必須由使用者確認本次必要查證已完成，系統不自行宣稱「完全沒有違規」。

§59 為例外規則，不是一般違規。若 §7 超標事實完整但 §59 六項條件也完整，全案不會單純以 §7 超標直接作成違規成立結論；若 §59 仍待確認，會保留事證不足提示。
