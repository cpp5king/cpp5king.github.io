稽查助手 4.3 手機版安裝說明

重要：PWA 第一次安裝不能直接由手機 ZIP／檔案 App 完成，必須先把本資料夾放在 HTTPS 靜態網站上並用手機開啟一次。安裝完成且離線快取建立後，即可在沒有網路時從主畫面開啟。

iPhone / iPad：
1. 用 Safari 開啟 4.3 的 HTTPS 網址。
2. 點 Safari 的「分享」。
3. 選「加入主畫面」。
4. 之後由主畫面「稽查助手」圖示啟動。

Android / Chrome：
1. 用 Chrome 開啟 4.3 的 HTTPS 網址。
2. 畫面若出現「安裝到手機」即可點擊；也可從 Chrome 選單選「安裝應用程式／加到主畫面」。
3. 安裝完成後由主畫面圖示啟動。

Windows：
維持原方式，解壓縮後直接雙擊 start.cmd，不需要網路，也不需要 PWA 安裝。

目前案件輸入仍沿用既有設計：只存在目前頁面記憶體，重新整理或關閉會清除；4.3 PWA 的「離線」是指程式本體可離線開啟，不代表案件資料已做永久儲存。
