# 4.4 → 4.7 開發階段

## 4.4｜案件工作流
- 手動匯出／匯入案件 JSON。
- 手機與 Windows 可用檔案接續同一案件。
- 不使用 SQLite、LocalStorage、IndexedDB 或雲端同步。

## 4.5｜特定業別子法 V1
- 管理辦法第9條相關業別：營建工地、預拌混凝土、採礦、土石採取、土石加工、土石方堆（棄）置場。
- 營建工地逕流廢水污染削減計畫支線。
- 畜牧沼液沼渣農地肥分使用計畫支線。
- 延續案件日期／法規版本保護。

## 4.6｜案件文字 V1
- 固定規則產生稽查紀錄草稿。
- 固定規則產生民眾回覆草稿。
- 不使用 AI；查察完成後才開放。

## 4.7｜UI 第二階段
- Desktop：完整表單。
- Mobile：聚焦目前尚未完成問題，已完成步驟可展開修改。
- Tablet：雙欄中間型態。
- 三種 UI 共用同一 Water Core。
