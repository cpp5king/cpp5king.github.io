# 第9條2.7更新

本版由2.6完整複製，只修改2.7的第9條。固定2分鐘、標準表、時段、天雨、測點、背景公式及工廠歲修背景流程保留。

## 操作與欄位

- 進入第9條即以前段已確認有噪音為前提，不再詢問可聞聲音及2分鐘完成確認。
- 不再選頻率。依適用標準顯示Leq、Leq,LF；只有營建工程另有Lmax。欄位空白代表未量測，不比較、不修正、不列入公文。至少輸入一項有效數據才能判定。
- 新增數值 `a9WindSpeed`（m/s），5以內可用、超過5不宜採用，缺漏不判定。重測功能保留。
- 內部 `availableItems` 是可輸入項目，`items` 僅包含實際填入的項目。兩者分開，防止空白項目被當成0。
- `a9CorrectionDetails` 為唯讀計算結果：原值、背景、修正後值（有修正時）、標準及最終結果；不允許人工填寫。所有必要背景處理完成且數據可採用後才顯示最終符合／超過。
- 比較精度及公式不變；使用2.6原始公式與機器精度處理，不新增小數位或四捨五入規則。

## 公文與法規資料

- 合格紀錄仍保存已進行的背景量測與修正結果。數值排列為全頻、最大、低頻，只列已填項目；民眾回覆維持簡潔。
- `data/rules/noise-article9.js` 各 `types[].legalBasis` 保存使用者核定之第9條第1項第1～6款對應；八種地方公告設施共用第6款。
- 原始量測與修正後值分別保留。超標仍為限期改善，不產生第一次超標直接告發。

## 檔案與驗證

修改第9條判斷器、量測流程、表單資料及公文資料／組合程式。通用引擎、第8條、第6條、餐飲與异味模組不改寫。

測試：`node --test tests/*.test.cjs`，148項通過、0失敗。新增14項2.7測試並更新已核定變更之舊欄位、風速及表單測試；保留時段、標準、天雨、背景差值、工廠歲修及其他模組回歸。
