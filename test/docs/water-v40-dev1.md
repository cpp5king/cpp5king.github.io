# 稽查助手 4.0-dev1－水污染模組第一階段

## 版本定位

本版由 3.7.1 完整複製建立，原 3.7.1 不修改。4.0-dev1 是 4.0 的第一個整合開發版，不代表水污染模組已完成。

## 已完成

- 首頁「水污染」正式開放，新增「水污染案件」直接入口。
- 新增 `WaterFacts` 統一案件事實層，不改寫既有 `CaseSession`。
- 新增通用水污規則評估器，規則資料與流程程式分離。
- 新增 Node 001～005：管制主體、廢（污）水、實際排放、最終去向、地面水體確認。
- 新增第14條第1項無許可排放核心檢核：水污法事業、廢（污）水、實際排放、排入地面水體、稽查時無有效排放許可。
- 結果使用 `☑ / ☒ / ?`，並輸出成立方向／不成立／事證不足、缺少要件及下一步查證建議。
- 道路側溝另提示排水功能、下游流向、排水體系連通，不因「側溝」名稱自動認定地面水體。
- 上游答案改變時清除不再有效的下游事實。
- 水污本階段只做判斷流程，不顯示「填入兩份草稿」功能。
