# 稽查助手 4.0-dev2－水污染多條文判斷

## 版本定位

本版延續 4.0-dev1，不覆寫 3.7.1。目標是讓同一份水污案件事實可平行供多條母法規則使用，而不是每個條文重新問一遍。

## 新增內容

### 第7條放流水標準

- 適用主體：事業、污水下水道系統、建築物污水處理設施。
- 與第14條排放資格平行判斷，不因有無排放許可而互相取代。
- 需確認排放廢（污）水於地面水體。
- 加入採樣、代表性、進入承受水體前之點位、適用標準、檢測結果及是否超標等證據節點。
- 未採樣、採樣無代表性或無有效檢測結果時，輸出「事證不足」，不以顏色、泡沫、臭味或混濁直接判定超標。

### 第18條之1

分成三條子規則：

1. 第1項繞流排放：需確認核准水路、現場實際水路、實際避開核准流程／非核准出口，並檢核第3項急迫搶救例外。
2. 第2項稀釋：確認原廢水須處理始能達標、實際混合稀釋、混入水無需處理即可達標，並先檢核第20條稀釋許可及第3項例外。
3. 第4項處理設施：確認現場有可檢視之廢（污）水（前）處理設施，並判斷功能／設備是否足夠及是否維持正常操作。

發現不明管線本身不等於繞流。

## 規則引擎更新

`WaterRuleEngine` 新增：

- `noMeans: insufficient`：已確認證據不足時，不誤判為法律要件不存在，例如「未採樣」。
- `noMeans: notApplicable`：主體或規則明確不適用時，輸出不適用而非事證不足。
- 四態結果：`established / notEstablished / insufficient / notApplicable`。
